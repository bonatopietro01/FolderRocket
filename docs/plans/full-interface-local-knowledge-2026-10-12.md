## Purpose

Complete the user-approved R1–R13 changes across FolderRocket while preserving the heavily modified starting worktree. The optional generative path may use only a separately installed local runtime; deterministic extractive processing remains available without it. Treat these as baseline to verify and extend, not as new work or as proof for this request.
- The completed UI plan `dashboard-planet-graph-cartoon-ui-2026-10-12.md` requested cartoon planets. This execution follows the newer confirmed preference in R12: align closer to FolderRocket and reduce caricature; keep persisted style IDs intact.
- Obsidian official docs consulted: a vault is a local folder; wikilinks use vault-root relative paths; Graph view lines represent internal links between note nodes. Every generated link must resolve to an existing generated note.
- Do not test against the user's real vault, documents, or personal Gmail account. Use synthetic fixtures. Never download/install/start a model automatically.
